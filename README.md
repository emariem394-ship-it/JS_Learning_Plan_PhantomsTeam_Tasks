# JavaScript Learning Plan — Phantoms Team

This repository contains the practical JavaScript tasks for university graduation team.

The purpose of this repository is to build a strong JavaScript foundation through 14 days of guided study, daily practice, and a final project. The plan covers JavaScript basics, data structures, functions, the DOM, events, and browser storage.

## Learning Plan

- **Duration:** 14 days
- **Level:** Beginner
- **Daily workload:** 2–3 hours
- **Structure:** Study, practice, complete the daily task, and review
- **Final project:** To-Do List application

## Getting Started

1. Clone the repository:

   ```bash
   git clone <repository-url>
   ```

2. Open the project folder in VS Code.

3. Open `index.html` in a browser.

4. Open the browser Developer Tools and select **Console** to view JavaScript output.

You can also use the **Live Server** extension in VS Code for a better development experience.

## Daily Workflow

For each day in the learning plan:

1. Study the assigned topic for 1–1.5 hours.
2. Practice the examples in the console or in `script.js`.
3. Complete and test the daily task.
4. Record the key concepts learned and anything that needs further review.

> The tasks are intended to be completed independently. Try to solve problems for at least 20 minutes before asking for help.

## 14-Day Curriculum

| Day | Topic | Main Task |
|---:|---|---|
| 1 | Introduction and setup | `Hello World`, variables, and environment setup |
| 2 | Data types and operators | Arithmetic, BMI, and equality operations |
| 3 | Conditions | Grade, leap year, and number comparisons |
| 4 | Loops | Multiplication table and FizzBuzz |
| 5 | Functions | Factorial, prime number, and string reversal |
| 6 | Arrays | Array operations and duplicate removal |
| 7 | Weekly review | Student grade calculator |
| 8 | Modern array methods | `map`, `filter`, `reduce`, and `sort` |
| 9 | Objects | Student objects and object methods |
| 10 | Strings, `Math`, and `Date` | Palindrome, random numbers, and formatting |
| 11 | DOM fundamentals | Interactive HTML elements |
| 12 | Events | Counter application |
| 13 | Final project — part 1 | Basic To-Do List |
| 14 | Final project — part 2 | Local storage, presentation, and README |

## Final Project

The final project is a complete **To-Do List** application that includes:

- Adding tasks
- Displaying tasks
- Deleting tasks
- Marking tasks as completed
- Preventing empty tasks
- Saving tasks with `localStorage`
- Showing total and completed task counts
- Clearing completed tasks
